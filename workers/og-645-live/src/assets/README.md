# OG fonts

Unmodified Pretendard 1.3.9 Regular and Bold WOFF files, from the `pretendard@1.3.9` npm package (`dist/web/static/woff`).

Upstream: https://github.com/orioncactus/pretendard

These are bundled as Workers Data modules, so Korean text rendering needs no runtime font request. The original SIL Open Font License is included in `Pretendard-LICENSE.txt`. Keep the license with redistributed fonts. Use the complete fonts rather than a subset of current article text, so newly published Korean titles render correctly.
